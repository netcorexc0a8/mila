# Mila

PWA для молодых мам: проверка банки детской смеси Nestlé по списку отозванных партий прямо в магазине.

Nestlé Россия отозвала часть партий NAN, NESTOGEN КОМФОРТ PLUS, PRENAN и ALFARÉ AMINO,
произведённых с 15.04.2025 по 27.11.2025 ([официальная страница](https://www.nestlebaby.ru/official-answer-otzyv)).
Отзыв идёт по **номеру партии** (10 букв и цифр на дне банки), а не по штрихкоду: штрихкод у всех партий одного продукта одинаковый.

## Что умеет

- Распознаёт номер партии камерой телефона (OCR на устройстве, без отправки фото на сервер) или из фото.
- Ручной ввод с подсказками: кириллические буквы, пробелы и путаница вида `0`/`O`, `8`/`B` учитываются.
- Предупреждает, если номер отличается от отозванного одним символом (опечатка или плохо пропечатанный символ).
- Показывает продукт и что делать: возврат, горячая линия 8 800 700 7979.
- История проверок на устройстве, полный список отозванных партий.
- «Мои партии»: можно добавить свои заблокированные номера (любой бренд, от 6 символов), при проверке приложение предупредит.
- Резервная копия истории и своих партий в файл.
- Работает без интернета: список партий встроен в приложение; движок распознавания кэшируется при первом запуске камеры.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm test         # Vitest
npm run build    # сборка в dist/
```

Список партий: [`src/data/recall.ts`](src/data/recall.ts). Логика проверки: [`src/lib/lot.ts`](src/lib/lot.ts).

## Публикация

GitHub Actions (`.github/workflows/deploy.yml`) прогоняет тесты, собирает и публикует сайт на GitHub Pages при каждом пуше в `main`.
Один раз нужно включить: **Settings → Pages → Source: GitHub Actions**.

Приложение неофициальное и не связано с Nestlé.
